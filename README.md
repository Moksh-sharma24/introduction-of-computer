## Introduction to Computers
A **computer** is an *electronic device* that accepts raw data as input, processes it using stored instructions, produces output, and stores the results for future use.

### Core Components
* Input Devices (Keyboard, Mouse)
* Central Processing Unit (CPU)
* Memory & Storage (RAM, SSD)
* Output Devices (Monitor, Printer)
